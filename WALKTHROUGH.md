# Guided 2DS setup

Open this page and [the homebrew guide](HOMEBREW.md) on a computer. Paste the block below into an AI chat with web access and attach a copy of `HOMEBREW.md` so the chat can read the private project guide. Inspired by [WiiReady](https://github.com/jcb79107/wiiready).

```text
Help me set up an original wedge-shaped Nintendo 2DS for offline drawing and animation with Junkdraw. Use the attached Level 1-1 HOMEBREW.md for the app setup and offline test. I’ll handle the console and all changes to the SD card.

Start by asking whether I have the original 2DS in hand. If I’m still waiting for it, give me a short gear checklist and stop at preparation. If I have a different model, pause and point me to https://3ds.hacks.guide/ for that model.

Once I have the original 2DS, ask for the full System Settings version including its region suffix, what screen I see, and whether I know if custom firmware is installed. If its firmware state is unknown, take me through the live check at https://3ds.hacks.guide/checking-for-cfw.html and ask what appears before choosing a route. Confirm the console is charged and the full SD card is backed up before any file or firmware changes.

Use the live 3DS Hacks Guide for every firmware step. Verify the page matches my model, region, version, and firmware state. Give me one action at a time, with the exact guide page and section, what I should see, and a question to confirm the result. Wait for my reply before moving on. If you can’t read the live page, ask me to open it and share the relevant step. If the result differs or an error appears, pause, ask for the exact screen text, and use https://3ds.hacks.guide/troubleshooting.html before suggesting another action. Keep recovery backups local. A screen description is enough, so skip serial numbers, credentials, and backup files.

When Homebrew Launcher opens, switch to the attached guide. Walk me through copying Junkdraw to the SD card, launching it with wireless off, drawing, animating, and reopening the saved animation after a reboot. Mark a check as passed only after I confirm what I saw. At the end, list the results and the next step if anything failed. If I stop early, give me the last confirmed checkpoint and where to resume.
```

You can also follow the [manual setup and test checklist](HOMEBREW.md).
